# 全部资源使用说明（Unity URP 14 项目）

> 适用版本：Unity 2022 LTS（URP 14）。资源根：`UnityFreeAssets\`（zip 为原件存档，**用解压出来的目录**）。
> 总原则：**模型用 FBX（优先）/OBJ；动画用 UAL2 单文件 fbx 提取；材质导入后跑一次 URP 转换器**。

---

## 0. 放入项目的两种方式
1. **直接复制**：把要用的包目录复制到项目的 `Assets\Art\` 下（推荐，简单）。zip 原件留在仓库外即可。
2. 想保持仓库整洁：复制到 `Assets\` 下按包名建文件夹，与项目脚本分离。

统一惯例：角色/武器导入后先看 **Model 标签页** → `Bake Axis Conversion` 勾选（Quaternius 官方要求，转了朝向才正确）。

## 1. Warden Boss 角色（01_Warden_Boss）

**文件**：`Knight Character by @Quaternius\FBX\`
- `KnightCharacter.fbx` — 重甲骑士本体（含基础动画，Humanoid）
- `Sword.fbx / ShortSword.fbx / Katana.fbx / Club.fbx` — 剑类（Katana 适合做 Boss 符文剑）
- `Helmet1-3.fbx / ShoulderPads.fbx` — 装甲件

**操作步骤**
1. 导入 `KnightCharacter.fbx` → Model：勾 Bake Axis Conversion；Rig：Animation Type = **Humanoid**（自动映射即可）；Apply。
2. 把 fbx 拖进场景做 Boss 预制体；剑/盾作为 `Weapon` 子物体挂到 **右手骨骼**（找手部骨骼节点，把武器 Pivot 对齐手心）。
3. **二阶段**：复制一份角色材质 → URP Lit 的 **Emission** 开 Max（选符文纹理/边缘发光色），在阶段转换事件里 `Renderer.material = phase2Mat` 或切换 MatPropertyBlock，配合 Shockwave + Mandala VFX。
4. **盾牌破碎版**：用 `RPG Pack\Shield.fbx` 在 Blender 里切开成 2~4 块 → 做成 `Shield_Broken` 预制体组，触发时替换。
5. 动画：见第 2 节，把 UAL2 片段塞进 Boss 的 Animator Controller（与玩家共享状态机结构）。

## 2. Warden / 玩家动画库（02_Warden_Animations）

**文件结构**
- `UAL2_Standard\Unity\UAL2_Standard.fbx` — **130+ 全部动画在同一个 fbx 里**（含 `UAL2_Standard.glb` 是 Godot/Unreal 用的，Unity 别用）
- `UAL2_Standard\Female Mannequin\` — 参考骨架与 README（骨骼命名参考）
- `UAL1_Standard\Unity\AnimationLibrary_Unity_Standard.fbx` — 第一代，替补

**官方导入三步**（包内 `Unity_Setup.png` 原图同款）：
1. **Model 标签页**：勾选 **Bake Axis Conversion** → Apply
2. **Rig 标签页**：Animation Type = **Humanoid** → Apply
3. **Animation 标签页**：`Root Motion Node` 设为 **Rig → root**（Root Transform 子项选 root）；所有 `*_loop` 结尾的动画勾 **Loop Time**；Apply

**拆分动画片段**：导入后展开项目视图里的 `UAL2_Standard.fbx` 节点，**子项就是全部动画 Clip**（每个都是一个独立子资产），直接拖进 Animator 用；也可以右键选中 fbx 点 "Extract"（按需全部提取为 .anim 文件）。所有片段均为 **In-Place**（位移靠代码/CharacterController 驱动），Root 曲线在 Animation 页确认无漂移。

**动作覆盖对照（你的需求清单）**
| 需求 | 来源 |
|---|---|
| 三段轻击/重击/大剑蓄力 | UAL2（attack 系片段） |
| 格挡/持盾移动/举盾受击 | UAL2 格挡+受击组合；**盾击、举盾姿态特化** → Mixamo 补 |
| 翻滚/前左右后位移/侧移/后退/转身/起步停步 | UAL2 全部有 |
| 直线冲锋 | UAL2 冲刺 + 代码驱动位移；或用 Mixamo charge 类 |
| 宽幅符文斩/地面施法/阶段转换 | UAL2 施法/大动作 + VFX（手动第 6 节那批 Asset Store 包） |
| 破势/死亡 | UAL2 受击/死亡；破势用"受击 + 慢放（Hit-stop）"组合 |
| 四向受击/治疗 | UAL2 受击/施法 + 状态机按方向选片段 |

> 官方建议：`Female Mannequin\Unity\Mannequin_F.fbx` 可直接用来建演示角色、快速预览动画。

## 3. 统一角色套件（03_Character_Kit）

**A. Quaternius RPG Characters（主角/祭司/法师首选，视觉统一）**
`RPG Characters - Nov 2020\` 包含 6 职业 + 各职业武器：
| 文件 | 对应你清单里的 |
|---|---|
| `Warrior`（+`Warrior_Sword`） | 完整主角 |
| `Cleric`（+`Cleric_Staff`） | **祭司**（法杖现成） |
| `Wizard`（+`Wizard_Staff`） | 法师系（备选/术士） |
| `Ranger`（+`Ranger_Bow`）/ `Rogue`（+`Rogue_Dagger`）/ `Monk` | 其他可用职业 |
- 都是同一作者同一骨架风格 → 满足"统一骨架比例"；有完整头脸。导入后 Humanoid 自动映射，动画全部用 UAL2 通用片段。

**B. 近战怪**
- `Animated Monster Pack by @Quaternius\`：`Skeleton.fbx`（骷髅战士，首选近战怪）、`Slime/Bat/Dragon.fbx`（其他怪物）
- `KayKit_Skeletons\addons\kaykit_skeletons\Assets\Characters\fbx\`：`Skeleton_Warrior.fbx / Rogue / Mage / Minion` + 盾/斧/弩/法杖配件（`Skeleton_Shield_Large_A.fbx` 等）—— 更精致的备选
- **注意**：KayKit 是另一风格，全怪统一用一家（别与 Quaternius 混用）

**C. KayKit Adventurers（备选整体方案）**
`KayKit_Adventurers\addons\kaykit_character_pack_adventures\Assets\Characters\fbx\`：Barbarian / Druid / Engineer / Knight 类 4 角色 + 武器（斧/弩/匕首）。
- 导入注意：KayKit 骨骼命名非标准，Humanoid 自动映射后需在 **Rig → Configure** 里手动核对一两个易错骨骼（手臂/脊柱），其余自动。

**通用做法**：所有角色做成同一个层级：`Root(Animator) -> Model`，Animator 用 UAL2 状态机（共享控制器），保证四类角色（主角/近战怪/祭司/盾卫）动作统一。盾卫（重盾兵）可用 RPG 包 Warrior + RPG Pack 大盾 + MedievalPack 鸢盾拼；或用 KayKit Skeletons 的盾兵。

## 4. 中世纪武器（04_Weapons）

**首选（FBX 可直接导入）**：`RPG Pack\FBX\` — **Shield（圆盾/纹章盾）、Staff（法杖）、IceStaff（冰杖）、Dagger、Book、Scroll、骑士盔**、宝箱等；`RPG Pack\Textures` 配套贴图。→ 玩家单手剑用 01 的 `Sword.fbx`（同源自带），Boss 符文剑用 `Katana.fbx` + 自绘符文贴图发光。
- 盾卫重盾：`MedievalPack`（鸢盾类）或 RPG Pack Shield 放大。
- **剑鞘/挂鞘**：免费库里没有，拿 `RPG Pack\Barrel` 的金属环 + 条状几何拼一个最省事。

**MedievalPack（OBJ/Blend）**：Unity 可直接导入 `.obj`（含 `.mtl` 时基本材质自动来，贴图可能需手动指定）；`.blend` 需本机装 Blender（Unity 自动调用转换）或手动在 Blender 里导出 FBX。
- **必做**：武器 Pivot 对齐握把中心（在 Blender 里把原点挪到握把中点再导出 FBX），米制比例复核（Quaternius 约定 1 单位 = 1 米）。

## 6. 战斗 VFX（手动下载后使用，见文末"手动清单 A"）
导入 Asset Store 那些免费包后：
- 进 **Project Settings > Graphics** 用 Render Pipeline Converter 把粒子材质升级 URP（或用包内自带的 URP 变体）；
- 刀光（Slash Effects）+ 剑刃拖尾（自己写 Trail Renderer）；
- 地面法阵（Magic Mandala VFX）放 Boss 脚下做地符/延迟爆炸圈；
- 冲击波（Easy Shockwaves）挂盾击/完美格挡瞬间；
- 爆炸（Free Fire VFX）挂符文剑命中点；
- 死亡消散 = Stylized Dissolve 思路的 Shader Graph（自写）或粒子扩散。

## 7. 遗迹/地下圣所环境（07_Environment_Ruins）

**主用（FBX 1:1）**
- `Updated_Modular_Dungeon\FBX\` — 石质地牢整套（`Arch/Arch_Door/Column/Floor/Wall/Stairs...` 直接导入）。**同包放在一个 Prefab 根下**，用网格吸附搭场景；材质是全包共用贴图（导入后 URP 材质球换 URP Lit）。
- `Medieval_Village_MegaKit\FBX\`（+glTF/OBJ 同款）— 木桥/栏杆/市政构件，跨区域用（桥、护栏、断桥替换件）。
- Boss 房：地牢包的大空间件 + 柱阵；围墙用 `Wall_*` 拼，门用 `Arch_Door_*`（含 pivot 版本，开门就是转门枢轴）。

**备选**：`KayKit_Dungeon_Remastered\addons\kaykit_dungeon_remastered\Assets\` — 只有 **glTF(.glb/.gltf) + OBJ**：Unity 用 `obj\` 目录导入（简单），或者装免费 glTF 导入包（UnityGLTF）用 glb。**风格另类，别和 Quaternius 混搭**；它适合整体换方案时用。
- 注意：地牢包 FBX 可能有非 1 米缩放/Pivot 原点在地面沿角，**导入后做 Prefab 时统一改 Pivot 到脚底角点**。

## 8. HUD/UI（08_HUD_UI）

**内容**：`_Kenney_UI_解包内容\` = UI Pack（PNG 九宫格 + SVG 矢量 + 2 款 TTF 字体 + 内置音效 ogg）、Pixel UI Pack（像素风）、Fantasy UI Borders（中世纪边框）。
- **九宫格**：PNG 拖入项目 → Texture Type = Sprite(2D and UI) → Sprite Editor 设 Border → UI Image 组件选该 Sprite，类型选 **Sliced**。
- **字体**：TTF 直接作为 Text 组件的 Font；Pixel 字体配 TextMeshPro 用 TMP 字体资产生成。
- **SVG**：需导入免费包 **Unity Vector Graphics**（Package Manager 搜索）才能用；不装就把 PNG 版本当图用。
- **协议横幅**（任务卡/装饰框）：用 Fantasy UI Borders 的边框 Sprite 拼九宫格。
- **按键图标**：Kenney 官网 Game Icons 系（手动清单 C），PNG 直接 Image。
- 音效：`_Kenney_UI_解包内容\Sounds\*.ogg` 挂 UI 点击事件。

## 9. 地表/植被/道具（09_Nature_Props）

导入优先级：**FBX（Unity）> FBX > OBJ**；Kenney NatureKit 是 OBJ/DAE/GLB/STL 多格式，用 `Models` 里的 OBJ 即可（Unity 直接导）。
- 树/灌木/岩石：`Stylized_Nature_MegaKit\FBX (Unity)\` + `Nature model pack\`（5 种树）+ `Ultimate Nature Pack - Jun 2019\`
- 篝火/帐篷/宝箱/药瓶/书卷/封印碑：`Fantasy_Props_MegaKit\Exports\`（导出好的格式）+ `Survival Pack - Sept 2020\` + `Ultimate RPG Items Pack - Aug 2019\`
- 苔藓石地/泥土/碎石：`Kenney_NatureKit\`（地形贴图+石块）；地表混合建议用 Terrain 工具 + 这些贴图，或直接铺地牢包地面件
- **烧痕/符文 Decal**：自绘 PNG → URP **Decal Projector**（Renderer 里加 Decal，材质用 URP Decal 类型）投影到地面。

## 10. 声音（10_Audio）

全部 **OGG**（Unity 导入即成 AudioClip）：
- `ImpactSounds\` — 金属/钝器/肉体命中、破裂（剑击、盾挡、盾破、重击）
- `RPGAudio\` — 法术、环境、脚步类（治疗、符文、施法）
- `InterfaceSounds\` — UI 点击/提示/确认
**用法建议**
1. 建 **AudioMixer**（Master → SFX / Ambience / UI 三组），代码里按类型播放到对应组。
2. 打击类：`Spatial Blend = 3D`、`Volume Rolloff = Logarithmic`、挂特效事件点/武器挂点播放。
3. 脚步：地面检测用 Raycast 判定材质 → 挑脚音频播放（RPGAudio 里挑）。
4. 转阶段短乐句/环境循环：当前 Kenney 包里只有零散音效，**暂未使用 Sonniss GDC 2024**（不下载）。后续要做环境循环/乐句时再补（Sonniss 或 Freesound），或先用 RPGAudio 的环境音循环 + 自组乐句。

## 11. 手动操作（你来做），之后并入项目

**A. Unity Asset Store 免费 VFX（6 个）**：登录 assetstore.unity.com → Add to My Assets（确认免费）→ 编辑器 Package Manager > My Assets 下载：
Slash Effects FREE / Magic Effects FREE / Magic Mandala VFX (FREE) / Easy Shockwaves VFX - URP / Free Fire VFX - URP（+可选 Human Melee Animations FREE、Free Low Poly Dungeon Pack）。
下载后：放入 `Assets\Art\VFX\`，粒子材质跑 URP 转换。

**B. Mixamo 盾牌专项动画**：mixamo.com 登录 → 搜 shield block / shield bash / charge / hurt → 下载 FBX for Unity → 拖入 `Assets\Art\Animations\Mixamo\`，Humanoid 自动映射，Clip 里清 Root 位移（In-Place），与 UAL2 共用 Animator。

**C.（可选）Kenney 按键图标**：kenney.nl 搜 Game Icons / Input Prompts，浏览器下载（无账号），解压到 `08_HUD_UI\`。

**D.（未使用）Sonniss GDC 2024**：暂不下载。哪天需要环境循环/大乐句，再到 sonniss.com/gameaudiogdc 取。

## 12. 常见坑速查
| 现象 | 处理 |
|---|---|
| 模型是躺着的/朝向反 | Model 页勾 **Bake Axis Conversion** |
| 动画没出来/只有一个姿势 | Rig 选 Humanoid 后展开 fbx 子节点，片段都在子项里 |
| 角色漂移回原点 | Animation 页 Root Motion Node = Rig→root；In-Place 片段别开 Root Motion |
| 材质全粉色/发灰 | 材质球换成 **URP Lit**；粒子用 Render Pipeline Converter |
| OBJ 没贴图 | 手动把 `Textures` 里的贴图指到材质上 |
| KayKit 骨骼怪 | Rig → Configure 手动核对手臂/脊柱映射 |
| 音频听不见/太远 | AudioSource Spatial Blend=3D，检查 Max Distance |
| UI 图片拉伸糊 | 设 Sprite 九宫格 Border + Image Type=Sliced |

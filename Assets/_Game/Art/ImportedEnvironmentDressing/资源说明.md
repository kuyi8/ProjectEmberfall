# 导入环境美术层

本层选用现有 KayKit Dungeon Remastered 1.0 的拱窗、斜断墙、基础立面和蓝旗，形成营地、庭院、离线首领区与圣所的上层轮廓。不是新玩法、通路或碰撞。

- 原件：`Assets/_Game/Art/DownloadResources/UnityFreeAssets/07_Environment_Ruins/KayKit_Dungeon_Remastered`，保持原字节和 GUID。
- 作者与来源：Kay Lousberg；本地原包 `LICENSE.txt` 明确 CC0，许可允许商用。官方作者地址见原许可 `www.kaylousberg.com`。这是既有用户导入包，本轮未下载；原获取时间未核验。
- 自有派生：`Prefabs` 是仅 Transform/MeshFilter/MeshRenderer 的静态包装，共享真实 FBX Mesh；`Materials` 使用原包调色纹理与项目 URP Lit 派生。蓝旗仅自有材质关闭背面剔除，原件不变。
- 布局：`layout.json` 由 Editor 生成器读取，使用既有可见墙顶作锚点，数据与搭建逻辑分离；不是运行时热更新包，也不改变 JSON/Lua 内容版本。
- 入口：`WorldPresentationSetup.ApplyToScene` 调用 `ImportedEnvironmentDressingSetup.ApplyToScene`。本轮只调用后者，不重跑 M6 场景全量生成或导航烘焙。
- 保护：独立根 `ImportedEnvironmentDressing`；无 Collider、Behaviour、Animator、Navigation/Lightmap Static 或 CameraOccluder，不隐藏旧墙、门或地面。不把挂点检查与两次 dressing 幂等称为全环境链重生成验收。

实际候选图与否决理由、正式相机范围和测试结果见 `CodexOutput/2026-10-02-真实导入环境美术批.md`。现有 r2 ZIP 不包含本层，后续出包需自己的回归、性能与库存证据。
